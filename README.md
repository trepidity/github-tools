# github-tools

Small tools for working with GitHub from the terminal.

| Tool | What it does |
|---|---|
| [gh-triage](gh-triage/README.md) | `gh triage`: create issues and repositories, triage issues, and review, approve, and merge pull requests |

See each tool's README for install and usage.

In `gh triage`, press `P` to switch between issues and pull requests. Open a PR and
use `f` to inspect changed files, `v` to review or approve, and `M` to merge.
